# Reading list (verify each citation before using it)
- RISC-V "V" Vector Extension specification (riscv.org / GitHub riscv/riscv-v-spec) [ref 1]
- Davis & Hu, SuiteSparse Matrix Collection, ACM TOMS 2011 [ref 2]
- Bell & Garland, SpMV on throughput-oriented processors, SC'09 [ref 3]
- Ara (Cavalcante et al., IEEE TVLSI 2020) and Ara2 - open RVV vector unit
- Sparse accelerators for context: SIGMA (HPCA'20), ExTensor (MICRO'19), SpArch (HPCA'20), OuterSPACE (HPCA'18)
- Indirect prefetching: IMP (Yu et al., MICRO'15)
- SELL-C-sigma (Kreutzer et al., SIAM SISC 2014)
